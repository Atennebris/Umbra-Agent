# Changelog

## [0.1.0] - 2026-06-07

### Added
- Initial public release
- Daemon-first architecture powered by PM2
- TUI interface built with Ink and React
- Provider support: OpenAI, Anthropic, Mistral, Ollama, LM Studio, and any OpenAI-compatible endpoint
- Autonomous Harness Loop — iterates on failing tests without user input
- Persistent session memory with SQLite
- Global memory across projects with vector search
- Web search tool
- File system tools: read, edit, write, list
- Shell execution tool
- Git Worktrees support for parallel agents
- AST-based context compression via Tree-sitter
- Cross-platform: Windows, macOS, Linux
